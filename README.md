# 🤖 S.I.R.I.U.S. v6.1 - Oficina Stark

Este é o meu assistente virtual inteligente desenvolvido do zero em Python para controle de estudos e comandos em texto livre.

## 🚀 O que ele já faz:
- Interpreta comandos digitados em linguagem natural.
- Salva e lê dados diretamente de um banco de dados JSON.
- Responde a cumprimentos chamando o Criador pelo nome.

## 🛠️ Tecnologias:
- Python 3
- Tkinter (Interface Gráfica)
- JSON (Banco de Dados)
